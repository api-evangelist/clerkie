Clerkie, operated by Henry Labs Inc. (San Francisco, founded 2016), is an AI-powered debt
management and loan-recovery platform for consumers and institutional lenders. Its B2B product,
Fiber, is an AI recovery platform for lenders, banks, credit unions, and collection agencies.

## What an agent should know first

- Clerkie markets a RESTful API to lenders, but publishes **no public developer documentation,
  no OpenAPI or other machine-readable contract, no SDK, and no self-serve developer portal**.
- There is no sandbox, no API key self-service, and no published authentication model.
- Integration is arranged through a sales conversation (HubSpot contact form), not self-serve.
- Do not attempt to synthesize Clerkie API calls. No endpoint list, parameter set, error catalog,
  or auth scheme is publicly available, and none should be inferred.

## API surface (as observed, not as documented)

- Clerkie API host: https://api.clerkie.io/ — live; the root returns a JSON health payload.
  Every other path probed anonymously returns HTTP 500. No specification is served.
- Fiber API host: https://api.getfiber.ai/ — fronted by an AWS load balancer; returns HTTP 403
  Forbidden on every path to an anonymous client.
